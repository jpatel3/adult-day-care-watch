# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In addition, because this project publishes information about real businesses and the people who run them:

- Discuss providers only in terms of what public documents say. No speculation about individuals, no contact with providers on the project's behalf, no doxxing.
- Treat corrections from providers or agencies as a priority, not an argument.

Report concerns by opening an issue marked "conduct" or by emailing the maintainer listed on the GitHub profile. Reports are handled privately.
